# Code film styles (Japanese)

[日本語](README.md)

Japanese folk tales, Japanese art styles and a Suno song, animated in HTML and code with no video model. Pictures are generated; motion, lettering and sound are code.

**Gallery**: https://yamamonlab.github.io/code-film-styles-ja/
