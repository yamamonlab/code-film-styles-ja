# コードで作る映像のスタイル集

[English](README.en.md)

日本の昔話と画風、Suno で作った歌ものの MV を、映像生成モデルを使わずに HTML とコードで動かした映像のスタイル集です。絵は画像生成、動き・文字・効果音はすべてコードです。

**ギャラリー**: https://yamamonlab.github.io/code-film-styles-ja/
